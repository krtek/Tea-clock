# Tea-clock
Steep your tea right.
## Intro
Currently running on [website](http://tea-clock.com) and listed as a Chrome Web Store [application](https://chrome.google.com/webstore/detail/hmldmlgafdbnfhhicheojakimpmocggp?utm_source=chrome-ntp-icon).
Written in Svelte 5, built with Vite.



## Setup dev environment
1. `npm install`
2. `npm run dev` - starts the dev server
3. `npm run build` - builds the production site to `dist/`

## Unit testing
1. `npm test`

Unit tests are located alongside their modules in `src/lib/*.test.js`.
